# POS Report Center v1.46.1

หน้า `pos-reports.php` รวมรายงานค่าดื่มและค่าคอมที่บันทึกแล้วในสาขาปัจจุบัน

- กรองประเภท สถานะ ช่วงวันที่ และค้นหาชื่อพนักงาน/ทีม/เลข Report
- Sort รอบจ่ายตามประเภท เลข Report วันที่ และยอดรวม
- Sort สรุปพนักงานตามชื่อ ตำแหน่ง D M ค่าดื่ม ค่าคอม และรวมรับ
- Export ตารางสรุปพนักงานเป็น CSV ตามตัวกรองปัจจุบัน
- ยกเลิกรอบค่าดื่ม/ค่าคอมแบบ Soft Delete โดยต้องกรอกเหตุผลและพิมพ์ `VOID`
- เคลียร์ Report ต้นทางแบบ Soft Delete โดยต้องกรอกเหตุผลและพิมพ์ `CLEAR`
- ระบบไม่อนุญาตให้เคลียร์ Report หากยังมีรอบจ่ายใช้งานอยู่ ต้องยกเลิกรอบจ่ายก่อน
- ทุกการยกเลิกและเคลียร์บันทึก Audit Log; ข้อมูลเดิมไม่ถูกลบออกจากประวัติ
