# ค่าดื่ม / ค่าคอม v1.46.0

แยกเมนูและรอบบันทึกตามสาขาออกเป็นสองส่วน:

- pos-drinks.php: ค่าดื่มส่วนตัว PR และ Sales จากจำนวนดื่มใน Report × อัตราที่กำหนด
- pos-commission.php: ค่าคอม Sales จากดื่ม PR ในทีม โดย Sales คนเดียวดูแลหลายทีมได้

แต่ละเมนู: เลือก Report ที่ Process แล้ว → กำหนดอัตรา → ตรวจผลและบันทึก ไม่สามารถข้ามไปบันทึกด้วย URL ได้ วันที่ใช้จาก Report และตรวจข้อมูลเปลี่ยนก่อนบันทึก

รอบเก็บแยกใน drink_payout_rounds และ commission_payout_rounds ไฟล์เดียวใช้ได้ทั้งสองส่วน แต่ห้ามบันทึกซ้ำในส่วนเดียว ข้อมูลและกติกาเดิมยังอยู่ ไม่ย้ายยอดเดิมมาเป็นยอดจ่ายใหม่อัตโนมัติ การ Import / Process ยังใช้หน้าระบบเดิมผ่านลิงก์ในหน้าเลือก Report

ต้องผูกเมนูกับ Employee Card ให้ครบก่อนบันทึก อัตรา D/M อ้างอิงตัวแยกรายงานเดิม

ยอดเมนู Sales คือดื่มส่วนตัว ไม่ใช่ยอดเชียร์ลูกค้า ค่าคอมจากยอดเชียร์ยังรอรายงานใบเสร็จ POS สำหรับจับคู่กับ Sales QR จึงยังไม่รวมในยอดจ่าย
